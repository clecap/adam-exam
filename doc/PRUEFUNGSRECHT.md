
Diese Datei enthält einige Überlegungen zum deutschen Prüfungsrecht.

**DISCLAIMER:** Diese Überlegungfen stellen keine Rechtsberatung dar, sind unmaßgeblich und möglicherweise falsch.

# Bonus / Malus Punkte
* Typischerweise sollen keine Bonuspunkte verwendet werden, wenn das nicht im Bewertungsschema transparent gemacht wurde.
* Typischerweise sollen keine Maluspunkte vergeben werden, erst recht nicht solche, die bereits erreichte Punkte wiederum reduzieren.
* Es ist aber zulässig, weniger als die volle Punktezahl zu vergeben, wenn etwas nicht optimal formuliert wurde.
* In Adam Exam wird das abgebildet, indem dem Korrektor ein User Interface für Bonus/Malus-Punkte zur Verfügung gestellt wird. Gründe können in einem Kommebntarfeld angegeben werden. 


# Gewichtungen

* Gewichtungen ind er bewertung sind möglich und können sich nach der Bedeutung und Wichtigkeit der Fragen orientieren. 
* Diese Tatsache sollte jedoch bei der Klausur erkenntlich sein.
* In Adam Exam wird das abgebildet, indem die maximal erreichbaren Punkte jeder Frage angezeigt werden.
